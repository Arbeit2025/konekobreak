# こねこ休憩リマインダー（konekobreak）

ブラウザ上の小さな猫が休憩を促してくれる、休憩取り忘れ防止の軽いタイマーページです。作業時間を設定して開始するとカウントダウンが始まり、時間が来ると猫のセリフが休憩メッセージに切り替わります。着想元は GitHub フォロワー yumiaura さんの myCat（デスクトップ猫オーバーレイ）です。

## 機能

1. **タイマー設定**：プリセット（25分／50分／90分）のボタン、または任意の分数（1〜999分）の入力で作業時間を設定します。
2. **カウントダウン**：残り時間を MM:SS 形式で表示します（ブラウザ側 JavaScript で動作）。開始・一時停止・リセットのボタンがあります。
3. **休憩メッセージ**：時間が来ると猫のセリフが休憩メッセージに切り替わり、猫が小さく跳ねるアニメーションとタイトル変更で知らせます。休憩メッセージはサーバー側（`app.py` 内のリスト、8件）からページに埋め込まれ、ブラウザ側でランダムに1件選ばれます。
4. **作業中のひとこと**：作業中は30秒ごとに猫のひとこと（応援・姿勢や水分補給の声かけ、6件）が切り替わります。

データの保存はしません（DBなし）。設定も履歴も残らない、開いて使うだけのツールです。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- カウントダウンはブラウザ側の JavaScript で行います。タブを閉じたり端末がスリープしたりすると止まります（音は鳴りません）。
- サーバー側に状態を持たないため、ページを再読み込みするとタイマーは初期状態に戻ります。
- ログイン機能はありません。
